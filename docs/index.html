Pillar 01

Loom RP2040 Architecture

Loom runs bare-metal on the Raspberry Pi RP2040. It replaces runtime C libraries and third-party RTOS kernels with language-level concurrency, MPU task sandboxing, and direct silicon coprocessor bindings.

Dual-Stack Sandboxing

Tasks run on PSP (Process Stack Pointer) in Unprivileged Mode. System services & ISRs run on MSP in Privileged Handler Mode.

Zero-Jitter SRAM VTOR

Vector Table is relocated to Scratchpad 0 (0x20040000). Interrupts dispatch in exactly 12 cycles without flash XIP cache penalties.

Hardware Coprocessors

Loom LLVM backend emits direct SIO hardware divider opcodes (8 cycles) and provides first-class syntax for PIO State Machines.

Pillar 03

Dual-Stack Concurrency & MPU Sandboxing

The compiler enforces privilege separation at call sites. User tasks execute in unprivileged Thread mode on PSP; kernel drivers run with full hardware access on MSP.

Dual-Stack Privilege Syntax
Copied 
Module ConcurrencyDemo

Import Target.RP2040.BSP.Thread
Import Target.RP2040.BSP.Gpio

Block Sensor_Worker()
    -- Executes on PSP (Process Stack Pointer) in Unprivileged Mode
    Loop
        Thread.Sleep_MS(100)
    End
End Sensor_Worker

Block Hardware_Driver()
    -- Executes on MSP (Main Stack Pointer) with Full Privileged Hardware Access
    Loop
        Thread.Sleep_MS(10)
    End
End Hardware_Driver

Block Main()
    -- Spawn unprivileged task on Core 0
    Spawn Sensor_Worker()

    -- Spawn privileged hardware driver
    Spawn Privileged Hardware_Driver()

    -- Spawn task pinned to Core 1
    Spawn Sensor_Worker() On Core(1)
End Main

Hardware Coprocessor

Pio: Programmable I/O State Machines

The RP2040 integrates two PIO units with four state machines each. These eight hardware engines execute bit-banging routines independently of the CPU at up to 133 MHz.

Module APIs
Init(Unit : Nat_32)
SM_Init_Default(Unit, SM, Offset, Pin)
SM_Set_FIFO_Join(Unit, SM, Join_Mode)
SM_Set_Shift(Unit, SM, In_Right, Auto_Push, Threshold)
SM_Set_Pin_Mappings(Unit, SM, Out_Base, Out_Count, Set_Base, Set_Count)
SM_Put(Unit, SM, Data) / SM_Get(Unit, SM)
IRQ_Set_Enabled(Unit, Irq_Idx, Enabled)
IRQ_Clear(Unit, Irq_Idx)
Complete PIO Example
Copied 
Module PioExample

Import Target.RP2040.BSP.Pio

-- Define assembly program inline
Pio_Program SquareWave
    Set(Pins, 1) [1]
    Set(Pins, 0) [1]
End SquareWave

Block Main()
    Pio.Init(0)

    -- Join RX/TX FIFO for 8-word deep TX buffer
    Pio.SM_Set_FIFO_Join(0, 0, FIFO_Join.Join_TX)

    -- Configure shift register and autopush at 32-bit threshold
    Pio.SM_Set_Shift(0, 0, Shift_Dir.Right, True, 32)

    -- Configure pin mappings
    Pio.SM_Set_Pin_Mappings(0, 0, 16, 1, 16, 1)

    -- Enable hardware interrupts
    Pio.IRQ_Set_Enabled(0, 0, True)

    -- Send 32-bit packet directly to state machine FIFO
    Pio.SM_Put(0, 0, 0xAAAAAAAA)
End Main

Sio: Hardware Divider & Inter-Core FIFOs

The Single-Cycle I/O (SIO) block contains an 8-cycle 32-bit hardware divider and an 8-entry bidirectional inter-core FIFO.

Copied 
Module SioExample

Import Target.RP2040.BSP.Sio

Block Main()
    -- 1. Automatic Hardware Division (LLVM lowers directly to SIO registers)
    Var A : Nat_32 = 1000000
    Var B : Nat_32 = 7
    Var Quotient : Nat_32 = A / B    -- Exactly 8 cycles!
    Var Remainder : Nat_32 = A % B   -- Read instantly

    -- 2. Non-blocking Division Pipelining
    Sio.Div_Start_Unsigned(0x12345678, 42)
    -- Do other CPU instructions here while SIO divides in silicon
    Var Result : Nat_32 = Sio.Div_Result()

    -- 3. High-throughput Inter-Core Hardware FIFO
    If Sio.FIFO_Is_Ready()
        Sio.FIFO_Push(0xCAFEBABE)
    End

    If Sio.FIFO_Has_Data()
        Var Msg : Nat_32 = Sio.FIFO_Pop()
    End
End Main

Reliability & Safety

Watchdog, Sync & Hardware Crash Diagnostics

Hardware spinlocks, recursive mutexes, watchdog timer configuration, and crash dumps stored across reboot in non-volatile scratch registers.

Safety & Diagnostics Example
Copied 
Module SafetyExample

Import Target.RP2040.BSP.Watchdog
Import Target.RP2040.BSP.Crash
Import Target.RP2040.BSP.Sync

Block Main()
    -- 1. Check if previous reboot was caused by an unhandled panic/hardfault
    If Crash.Did_Crash()
        Crash.Print_Crash_Report()
        Var Fault_Address : Nat_32 = Crash.Get_Last_PC()
    End

    -- 2. Arm hardware watchdog with 2000 ms timeout
    Watchdog.Enable(2000)

    -- 3. Hardware spinlock synchronization across Core 0 and Core 1
    Var Lock : Mutex = Sync.Create_Mutex()
    Lock.Acquire()
    -- Critical Section
    Lock.Release()

    -- 4. Feed watchdog in main supervisory loop
    Watchdog.Feed()
End Main
